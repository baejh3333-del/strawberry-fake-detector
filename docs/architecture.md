# 모델 구조 명세


## 문제
- 딸기 시설재배 이미지가 실제(0)인지 생성·합성·변형(1)인지 이진 분류.
- 평가 524장(실제 262 / 가짜 262), 확률 ≥ 0.5 → 1. 주지표 Accuracy, 동점 시 AUROC → F1.
- 가짜 6유형: ① 전체 생성 ② 합성 ③ 지정 필터(블러·노이즈·소금후추·JPEG) ④ 전체 스타일 변환 ⑤ 부분 생성 ⑥ 부분 스타일 변환.
- 대회가 공개한 예시 이미지는 21장뿐(실제 3 + 유형별 3). 학습 데이터는 **팀이 직접 구성**해야 했다 → 이 프로젝트의 절반은 데이터 만들기. ([data-and-generation.md](data-and-generation.md))

## 최종 모델

```
원본 1024×768 (줄이지 않음)
 ├─ 256×256 조각 12장(4×3) ─ DINOv3 ViT-L/16 (고정, 303M)
 │      └ 패치 토큰 3072개 × 1024차원
 │            ├ Gate (attention pooling → softmax)   : Expert 비중
 │            └ Expert × N (attention pooling)        : 각자 64차원 특징 + 점수 1개
 └─ 원본 통째 ─ EfficientNet-B0 "Common CNN" (1280차원)
         ↓ concat (64 + 1 + 1280 = 1345)
       MLP (→256→1) → sigmoid → 확률
```
- 총 311M 파라미터, 가중치 0.64GB. T4에서 524장 약 152초(한도 5분).
- 최종 변형(exp11b): Expert를 계열 5개가 아니라 **생성 방식별 24개(gen24)** 로, 예시 이미지에서 반응이 없던 11방식은 학습 가짜에서 제외.
- v5: 마지막 층 bias에 +2.9444(= ln 19)를 더해 판정 문턱을 p ≥ 0.05로 이동(모델·AUROC는 그대로).

### 학습 3 stage
1. Expert와 Common 학습 (백본은 사진당 1회만 계산, 각 Expert는 "실제 + 자기 계열 가짜"만 봄)
2. Gate만 학습
3. 전체를 낮은 learning rate로 학습. loss = `BCE + 0.2·Gate CE + 0.1·SupCon` (SupCon은 같은 원본의 실제·가짜 쌍)
- 기본 1500/400/1500 step, batch 8. 샘플링은 실제:가짜 1:1, 가짜는 계열 균등, augmentation은 좌우 뒤집기만.

## 왜 이렇게 골랐나
| 선택 | 이유 |
|---|---|
| 줄이지 않고 **조각으로 자름** | 블러·VAE 8픽셀 격자·부분 편집 경계 같은 픽셀 단위 흔적은 축소하면 사라짐. 1024 통째 입력은 학습 크기보다 큰 입력에서 DINO 정확도가 떨어진다는 보고(81.8%→71.3%)가 있어 기각 |
| **DINOv3 고정** | 고정 상태로도 처음 보는 생성기에 강하다는 보고. 데이터가 계열당 수백~천 장이라 미세조정하면 우리 생성기 지문을 외울 위험 |
| **attention pooling** | 부분 편집은 일부 조각에만 흔적이 있어 평균하면 묻힘 |
| **Common CNN** | DINOv3는 저주파에 기대는 경향. 필터(③)의 고주파 흔적은 크기 제한 없는 CNN이 보완 |
| **MoE (Expert 여러 개)** | 생성기마다 지문이 다름 |

> **Honest note**
> "MoE가 단순 평균보다 낫다"는 비교 실험은 계획만 하고 **하지 않았다**. 구조 선택은 실험이 아니라 설계상의 논리에 근거했다. 그리고 이후 구조 실험들은 대부분 효과가 없었다. → 모음
