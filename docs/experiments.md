## 사전에 정한 채택 기준 (exp15~18)
결과를 보기 전에 고정:
- 처음 본 방식 균형 **+3%p 이상**
- 실제 정확도 ≥ 0.985
- AUROC 하락 ≤ 0.003
- 유형별 recall 하락 ≤ 5%p, 전체 균형 하락 ≤ 0.5%p
- 이유: val과 리더보드 격차가 크고, 마감 뒤에야 점수가 나와 모델을 리더보드로 검증할 수 없어서.

## 패턴 정리
- **효과 있었던 것**: 라벨(family) 재배정, 학습 방식 선택(학습 불가능한 양성 제거), 판정 문턱 이동
- **효과 없었던 것**: LayerNorm, 풀링 방식, 입력 채널, dropout, 스펙트럼 특징, 가중치 비중, 학습량 2배, Expert 개수 조정(죽은 Expert 11개를 빼도 점수 동일)
